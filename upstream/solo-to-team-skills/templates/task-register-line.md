# 派收登记行（复制用）

用法：每派出一件需要回收的活，复制一行到当天的派收／接力记录。**只追加，不改、不删已写的行**：状态变了就在下面追加一行新状态，开头写同一个「任务标识」，原来那行的字段（尤其原预计交时、结果放哪）原样留着。

按任务标识看最近有效的任务阶段，不按物理末行的名称筛选：

| 状态 | 意思 | 还在未完清单里吗 |
|---|---|---|
| `待收` | 活已派出（或开跑），还没人确认接下 | 在 |
| `已接单` | 执行人确认接下这件活，**成果还没到** | 在 |
| `已收到成果` | 交付物已到约定位置，收的人看见了；标明待核，或核验通过待有权者决定 | 在 |
| `退回` | 发现缺项，等执行人补交；之后的续期／升级不改变这个阶段 | 在（等重交） |
| `已验收` | 当前版本核验通过，且有权接受者已接受或依明确适用的既有授权接受；记录接受者与依据 | **不在了** |
| `已取消` | 有权拍板的人明确说不做了 | **不在了** |

`叫开工`、`续期`、`升级`只记过程，不改变任务阶段；连续多条也回看最近有效阶段。`叫开工｜尚未回`仍待接单；有明确接单回执或开工证据，再追加`已接单`。点名汇总不改变单项状态；无法识别的记录先保留原阶段并核清，不据此销项。只有符合上述条件的已验收或授权取消才结束这一单；后续过程行不重开旧单。新一单或另开一轮，一律用新任务标识登记待收，不复用旧标识；同一单未结束的退回补交仍沿用该单标识。旧单迟到补记只归旧单，不改变新单阶段。

核验人已有明确适用的接受权限时，直接按原授权验收，不重复询问；没有时只记核验通过待决定。执行人自查不替代原任务要求的独审，验收不自动授权发布、付款等其他动作。

注意：
- **等待结束 ≠ 成果回来**。后台命令停了、对方说「好了」，都要去结果该在的地方看；看到了才写 `已收到成果`，没看到仍是未完。
- **到点查所有未完项**：不只查没人接的；已接单到点没交、已收到成果还没核、退回等重交的，都按各自状态去查（对应节点见 `../skills/dispatch-accept-verify/SKILL.md` 第 3 节）。查的时间点可以是预计交时＋约 5 分钟，这只是示例，按任务时限调整。
- **到点谁查要写具体的人**：他可能不在线，就写授权接替人，或他下次能查的时间。实际查晚了照实记，不写「已兜住」。
- **新预计 ≠ 正式改期**：写 `续期` 行，原承诺、原因、影响都留着；执行人报的新时间只是新预计，有权的人（一般是总控，在已有权限内）确认后，追加一行写明谁确认，才算正式改期。确认前仍按原承诺算逾期。
- 核对技能 evidence-before-done 的位置：`../skills/evidence-before-done/`（相对本文件）。

## 待收（开跑当下写）

```
待收｜任务标识：________｜什么活：________｜谁在干：________｜谁来收：________｜预计交时：____-__-__ __:__｜到点谁查：________｜若不在线：授权接替人________／下次可查时间__:__｜结果放哪：________｜做到什么算完：________｜建议下一棒技能：（可空）
```

## 已接单（执行人确认接下；成果还没到）

```
已接单｜任务标识：________｜几点：__:__｜谁接的：________｜预计交时：（不变则写「同原行」）
```

## 已收到成果（交付物到了约定位置；待核或核验通过待决定）

```
已收到成果｜任务标识：________｜几点：__:__｜结果在哪：________｜是不是约定位置：是／否｜核验：待核／通过（依据：________）｜接受决定：待核后处理／待有权者决定
```

## 已验收（核验通过并有权接受；退出未完清单）

```
已验收｜任务标识：________｜几点：__:__｜谁核的：________｜怎么核的（一句话）：________｜谁接受：________｜接受决定／既有授权依据：________｜交给谁／关闭：________
```

## 退回（核了没过；仍在未完清单）

```
退回｜任务标识：________｜几点：__:__｜缺什么／错在哪：________｜已告知执行人：是／否｜新预计（执行估计）：__:__｜正式改期：未确认／已由____确认
```

## 已取消（有权的人拍板不做；退出未完清单）

```
已取消｜任务标识：________｜几点：__:__｜谁拍板：________｜原因一句话：________
```

## 到点未完（续期；不覆盖原承诺）

```
续期｜任务标识：________｜原承诺：__:__（保留）｜新预计（执行估计／建议）：__:__｜正式改期：未确认／已由____确认｜原因一句话：________｜影响：________｜仍由谁收：________
```

有权的人确认后，再追加一行同格式的 `续期`，把「正式改期」写成「已由____确认」；原承诺那一格照旧保留。

## 过点升级（没人接、到点没交、交了没核，追不上时）

```
升级｜任务标识：________｜原行摘要：________｜当前状态：________｜实际几点查的：__:__｜过点时长：__｜谁在追：________｜下一步：________
```

## 放行后叫开工（授权／放行一出当场写）

```
叫开工｜任务标识：________｜放行／授权摘要：（不写密钥）｜执行人：________｜交付物：________｜交时：________｜对方回执：已接单（几点）／开工证据在________／尚未回
```

## 开工／收工点名（扫自己派出的、还没「已验收」或「已取消」的活）

按上面的最近有效阶段扫：待收（含叫开工尚未回）、已接单、已收到成果（待核或核验通过待决定）、退回。续期、升级、叫开工不代替阶段；只在有效验收或授权取消后退出。

```
点名完｜剩 N 件｜最早到点：__:__｜过点未接单：N｜已接单到点未交：N｜成果到了未核：N｜核验通过待决定：N｜退回待重交：N｜新预计未确认：N｜需报新时间：N
```
