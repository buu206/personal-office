# v0.2.0 · 四平台完整包与完整 MAS

每个平台各有一个完整包：1款平台协作Skill＋4款完整基础Skills，加上岗位/群规、配置、模板、示例、建队台及接续工具。原MAS工具与原四Skill独立入口保留，四包包装bundle.1沿用adapter.5原生载荷。

用户包、PDF与原生载荷保持已核字节。公开打包源码对扫描器做一处通用化：去除内部聊天标记，并将具体用户名路径改为通用用户目录模式；同步明确PDF不是本打包源码的重建对象。此变化不改四个用户包。

发布编号v0.2.0标识本次公开整合，不能代替宿主验收。包内历史“候选/未正式发布”字样描述材料冻结时状态及原生验证范围，不表示本次下载入口不存在；内层平台Skill身份仍按各自清单保留。旧文中暂不上传的历史决定已被本次发布决定替代。

已核文件、相对引用、配置计数、指纹与重建；bundle.1四端完整原生采用尚未验证。Grok doc1正文和manifest回件核同；调用及五参考可读为对端自报。旧design2业务与人工双Bot审阅只归旧版。不承诺自动建队、全16席四端稳定运行或自动跨端调度；现役团队未用于试装。

## English

v0.2.0 is the public integration version. Four bundle.1 archives each contain one platform collaboration Skill and four complete foundation Skills, with configuration and workflow materials. The original MAS and standalone Skills remain available. Native payloads retain their adapter.5 identities.

Candidate/unpublished labels inside frozen payloads describe the material's earlier snapshot and bounded native acceptance; they do not override the current release entry. The packaging-source scanner now uses a generic user-path pattern and no private chat identifier. The four user archives are unchanged. PDF maintenance source is not part of this bundle builder.

File/build checks do not prove complete native adoption of the new bundles. Grok returned body and manifest bytes match; invocation and reference readability remain self-reported. Historical business evidence remains tied to its tested version. No universal installation, automatic cross-platform orchestration or full-team long-term acceptance is promised.
