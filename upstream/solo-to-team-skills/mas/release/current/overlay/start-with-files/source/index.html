带底稿开工

把手里的原件和任务要求装进一个新项目，交给自己的首席。

底稿原件

1–8 份，每份不超过 12 MiB，合计不超过 32 MiB。支持普通文档、无宏 Office、PDF 和图片。

支持的格式与同名处理

MD、TXT、CSV、PDF、DOCX、XLSX、PPTX、PNG、JPEG、WebP。同名文件各有独立序号；原名、字节数和指纹都写进随包清单。
