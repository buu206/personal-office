# 带底稿开工 / Start with your drafts

双击 **[带底稿开工.html](index.html)**。选入已有底稿，写明任务和验收点，再选“只收件”或“确认后开始制作和独审”。默认由首席执行官、生产官、审核官三席接力；也可选用已有的中性团队 JSON。生成器会检查 DSH 所需的派工与交回归属。

下载后把 ZIP 解压到**新空目录**。保留隐藏的 `.dsh`，在 DeepSeek Harness 0.2.1-rc.5 打开能看到 `JOB.json` 的那一层。打开包内 `START.md`，在自己的主会话选 `/solo-to-team` 并发送对应授权消息。此后真正的补充或变更再发到同一会话。

- 底稿为 1–8 份，单件最大 12 MiB，合计最大 32 MiB。支持普通文字、CSV、PDF、无宏 Office 和 PNG/JPEG/WebP。页面列出每个原始文件名和大小。只选择自己有权交给宿主的材料。
- 每份文件原字节放入 `inputs/originals/`，采用独立编号；同名和非 ASCII 文件可同时保留。按 `inputs/manifest.json` 的原名、包内路径、字节数和 SHA-256 核对。任务与验收点单独存入 `JOB.json`。文件正文不会拼进团队的固定岗位指令。
- 选“只收件”时，第一条消息要求首席在原会话确认底稿及原版号或未编号。选“开始制作”时，只有在用户发送开工消息后，团队才有此次制作与独审的直接委托。
- 生成中可取消；“清空本页”只清掉表单和当前页面内存中的文件选择。原件在原目录保持原状。不同项目的下载名带本次授权范围和 ZIP 内容短指纹，便于保留多个版本。登记和下载均在本机完成，不需要联网、登录或模型。把新项目交给宿主办单时才涉及它自己的模型、费用及权限。

**English.** Open [the local page](index.html#en). Attach 1–8 files (12 MiB per file, 32 MiB total), enter the task and acceptance criteria, choose receipt-only or production-and-review, then download the new workspace. The starter has a lead, producer and independent reviewer. You may instead select a compatible existing team definition. Extract into an empty folder, keep `.dsh`, select the folder containing `JOB.json` in DeepSeek Harness, and follow `START.en.md` in your own root chat. Send later amendments to that same chat.

Each downloaded project is named with its scope and a short SHA-256 fingerprint of the ZIP. The manifest records the original filename, safe numbered internal path, size and SHA-256 for each source. Original bytes are preserved. The page does not send files or persist them in browser storage. Only give your selected host material you are entitled to share. No model is used to build the ZIP; actual execution depends on that host’s available model, tools and permissions.
