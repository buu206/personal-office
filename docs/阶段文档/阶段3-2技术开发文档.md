# 阶段3-2技术开发文档

2026-11-18。范围：统一三个本地工具页的视觉和导航，保持配置编辑、素材打包、版本合并的既有业务行为；完成本地验收。主场景沿用已确认的二维宝可梦伙伴，不增加真实模型或线上功能。

## 规则与手册适配

沿用前端适配声明与已确认 D11：JavaScript 原生静态界面，无 TypeScript；无模型调用，真实冒烟 N/A。持久化为工作台浏览器存档及工具导出的 JSON/ZIP。前端手册的 TypeScript、真实模型联调和云端准备要求在本路线不适用，按 AGENTS 十条底线和已确认声明执行；建议手册增加纯本地工具分支。其他适用安全要求不变。

## 实现

- `frontend/tools/theme.css`：草绿/奶油底色、精灵球导航、金色按钮、红色卡片侧栏、焦点样式与窄屏布局。
- `frontend/tools/skin.mjs`：构建时为三个独立工具页添加公共导航和样式。团队编辑与配置更新原脚本逐字节一致；素材打包脚本通过受检查的构建适配器增加缺项提示，重新计算该脚本 SHA256；样式追加准确的 style SHA256，不放宽 CSP。
- `frontend/build.mjs`：从上游只读快照生成换肤页面，记录三页产物哈希。上游源文件、测试、文件格式不改。
- `frontend/tests/tool-skin.test.mjs`：校验脚本不变、实际 style 内容与 CSP 哈希吻合、返回入口和当前页标识、源结构变化时显式失败。
- `config/verification.json` 与根 `verify.sh`：仅显式加入个人办公室阶段3-2；复用正式前端测试/构建/恢复检查。20项隔离闸门回归验证失败传播、旧阶段配置兼容、未授权阶段拒绝及其他产品行为。

## 使用与数据

三个工具从工作台顶部进入，也可以相互切换并返回工作台。切页前先保存编辑的配置，浏览器下载的 JSON 可重新打开；素材与版本合并页面不保存文件选择。工具下载文件不自动覆盖工作台团队，需要在工作台设置中导入。主场景任务进度仍为模拟；JSON/ZIP生成与版本合并是真实本地操作。

## 验证与交付

详见 `docs/evidence/阶段3-2/`。真实浏览器验证下载→重载→导入、生成ZIP→核对原件与任务、三方冲突→人工选择→核对下载JSON；三个页面检查桌面与390px窗口。手机真机由用户验收，不把窗口模拟写成真机。共用验证结果以 `verify-输出.txt` 为准；等待用户验收，不自动进入上线。

用户反馈修复：`frontend/tools/pack-feedback.mjs`从既有打包状态生成缺项说明，涵盖缺材料、空任务/标准、团队读取/无效及重新授权。构建严格匹配唯一适配位置，结构不符即失败；仅添加提示，不改校验和生成逻辑。自动化增加4项行为回归，三页全部内联脚本与样式均核验CSP。
